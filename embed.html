What is a Unix timestamp?

A Unix timestamp (epoch time) is the number of seconds elapsed since 00:00:00 UTC on 1 January 1970. It is timezone-independent and used everywhere in programming. This widget shows the current value, updating every second. Need to convert a specific value? Use the epoch converter, and see the Unix time guide for background.
